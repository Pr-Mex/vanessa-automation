# Замер покрытия кода при выполнении сценариев

Vanessa Automation умеет собирать покрытие кода тестируемой информационной базы с помощью команд конфигуратора `1cv8.exe DESIGNER`, появившихся в 1С:Предприятие 8.5.5.

Основной формат результата — `.ccf` (стандартный формат 1С). Дополнительно можно выгрузить замер в формате SonarQube (`.xml`). Формат `.pff` не используется: программного API для его получения нет.

## Требования

* 1С:Предприятие 8.5.5 или выше.
* Пользователь информационной базы с правами администратора.
* Доступ к исполняемому файлу `1cv8.exe` (конфигуратору) на компьютере, где работает Vanessa Automation.
* Для серверной информационной базы — соединение с сервером 1С:Предприятие. Для файловой — путь к каталогу базы или строка `File="..."`.

## Настройки

Настройки находятся на закладке **Отчет о запуске сценариев** в группе **Замер покрытия кода**.

| Настройка | JSON-ключ | Назначение |
|---|---|---|
| Собирать данные по покрытию кода | `CollectCodeCoverageData` | Включает замер. По умолчанию выключено. |
| Режим замера | `CodeCoverageMeasurementMode` | `ЗамерДляКаждогоСценария` — отдельный файл после каждого сценария; `ЗамерДляВсегоПрогона` — один файл на весь прогон. |
| Каталог выгрузки замеров | `MeasurementsOutputDirectory` | Каталог для файлов замера, служебных логов и манифеста прогона `measurements_<ИД прогона>.tsv`. Если пусто, используется подкаталог `ПокрытиеКода` каталога проекта. |
| Формат результата | `MeasurementResultFormat` | `Стандартный` (`.ccf`) или `SonarQube` (`.xml`). |
| Путь к конфигуратору | `DesignerPath` | Путь к `1cv8.exe` или каталогу `bin`. Если пусто, конфигуратор определяется автоматически. |
| Строка соединения с базой | `InfobaseConnectionString` | Явная строка соединения. Если пусто, используется строка соединения текущего профиля клиента тестирования. Тип клиента определяется по текущему профилю; если профиль не выбран, используется `ThinClient`. |
| Логин администратора сбора данных по покрытию | `CodeCoverageAdminLogin` | Логин администратора. Если пусто, берётся из строки соединения (`Usr=`). |
| Пароль администратора сбора данных по покрытию | `CodeCoverageAdminPassword` | Пароль администратора. Хранится в настройках в открытом виде и маскируется при вводе. Если пусто, берётся из строки соединения (`Pwd=`). Пароль лучше задавать в этом поле, а не в строке соединения. Не допускаются кавычки, `%`, `!`, `&`, `|`, `<`, `>`, `^` и переводы строк. В MCP значение `*****` означает «не менять»; в строке соединения маску `Pwd=*****` можно оставить при изменении остальных параметров — сохранённый пароль будет подставлен. |
| Останавливать прогон при ошибке замера | `StopRunOnMeasurementError` | Если включено, ошибка запуска или завершения замера останавливает выполнение сценариев. |

## Как это работает

1. Перед началом прогона (режим «весь прогон») или перед каждым сценарием (режим «каждый сценарий») Vanessa Automation запускает:

   ```
   "C:\Program Files\1cv8\8.5.5.1219\bin\1cv8.exe" DESIGNER /F"C:\base" /N"admin" /P"password" /StartCodeCoverageAnalysis -parameters "parameters.xml" /out "start.log" /DisableStartupDialogs /DisableStartupMessages
   ```

2. После завершения сценария или прогона Vanessa Automation запускает:

   ```
   "C:\Program Files\1cv8\8.5.5.1219\bin\1cv8.exe" DESIGNER /F"C:\base" /N"admin" /P"password" /FinishCodeCoverageAnalysis -result "measurement.ccf" -format standard /out "finish.log" /DisableStartupDialogs /DisableStartupMessages
   ```

3. Файл параметров замера создаётся автоматически. Для файловой базы включаются клиентская цель (`ThinClient`, `ThickClient` или `WebClient` по типу профиля) и `FileVariantServerSide`, для серверной — клиентская цель и `Server`. Модули не исключаются.

4. Все запуски конфигуратора выполняются синхронно, без таймаута. В журнал регистрации записывается начало запуска и команда без пароля.

5. Ошибка запуска или завершения замера записывается в журнал регистрации и, если каталог замеров уже подготовлен, в манифест прогона.

## Идентификатор замера

Идентификатор сценария состоит из:

* полного пути к файлу фичи;
* имени сценария;
* номера строки сценария;
* номера примера для `Scenario Outline`;
* номера попытки при повторах.

Нумерация примеров в идентификаторе и манифесте начинается с 1, чтобы пример не смешивался со сценарием без примеров (там номер примера равен 0).

Для режима «весь прогон» используется идентификатор прогона. Идентификатор прогона также хранится в отдельной колонке манифеста, чтобы различать повторные запуски одного и того же сценария.

Имя файла замера формируется из имени фичи, имени сценария, номера строки, номера примера и номера попытки. Запрещённые символы заменяются на `_`, длинные имена сокращаются, в конец имени всегда добавляется короткий хеш с идентификатором прогона.

## Манифест

В каталоге замеров создаётся файл `measurements_<ИД прогона>.tsv` с колонками:

```
ДатаВремя	ИД	ИдентификаторПрогона	ПолныйПутьКФиче	ИмяСценария	НомерСтроки	НомерПримера	Попытка	Статус	ФайлЗамера	КодВозврата	Ошибка	Комментарий
```

Он позволяет сопоставить каждый файл замера (`.ccf` или `.xml`) с конкретным сценарием, примером и попыткой.

## Готовый пример запуска

В поставке есть файлы:

* `tools/MeasureCoverage_855_UF.cmd` — сборка Vanessa Automation и запуск замера;
* `tools/JSON/MeasureCoverage_855.json` — настройки сессии;
* `tools/JSON/VBParams855UF_MeasureCoverage.json` — параметры Vanessa Automation с включённым замером.

Запуск:

```
tools\MeasureCoverage_855_UF.cmd
```

Скрипт `.os` запускает сессию проверки поведения и ждёт её завершения. Завершение замера всегда выполняет сама Vanessa Automation, в том числе при закрытии формы и аварийном завершении прогона.

Пример рассчитан на файловую базу без пароля. Если в тестовой базе у пользователя есть пароль, заполните `ЛогинАдминистраторСборДанныхПоПокрытию` и `ПарольАдминистраторСборДанныхПоПокрытию` в `tools/JSON/VBParams855UF_MeasureCoverage.json` или используйте отдельный профиль клиента тестирования с этими параметрами.

## Ограничения

* Не поддерживается веб-клиент Vanessa Automation.
* В первой версии поддерживается только Windows. На платформах ниже 8.5.5, в веб-клиенте и Linux группа настроек скрыта, замер не запускается.
* Пароль администратора передаётся конфигуратору в командной строке и хранится в настройках в открытом виде. В журнале регистрации и MCP-ответах пароль и значение `Pwd=` в строке соединения маскируются. Файл выгрузки настроек VAParams содержит пароль в открытом виде — храните его безопасно. Используйте отдельную учётную запись с минимально необходимыми правами.
* При закрытии формы Vanessa Automation завершает активный замер. Если процесс завершён принудительно, завершить замер нужно вручную командой `/FinishCodeCoverageAnalysis`.
* Для файловой базы в момент замера к ней должны быть разрешены подключения. Если база открыта монопольно, запуск конфигуратора завершится ошибкой.
