# 📋 Параметры конфигурации

> **Назначение:** Этот файл содержит параметры текущего проекта покрытия тестами.
> Все субагенты ОБЯЗАНЫ прочитать этот файл в начале работы и использовать
> значения из таблицы ниже вместо хардкоженных путей.
>
> **При первом запуске** заполните все пустые значения. После этого менять
> параметры нужно только при изменении инфраструктуры (перенос базы,
> обновление платформы, перенос исходников).

## 📖 Пояснения по параметрам

### 1. Имя проекта
Короткое имя проекта латиницей (используется в ТестПлан.MD и именах файлов).
Пример: `testERP4`, `testBuh3`, `testZUP3`.

### 2. Имя профиля клиента тестирования
Имя профиля, заданного в Vanessa Automation. Получить список:
```
manage_test_client_profiles(action="get_list")
```
В поле «Имя» каждого профиля — нужное значение.

### 3. Путь к DT-эталону
Полный путь к DT-файлу с эталонным состоянием тестовой базы.
Пример: `C:\Commons\rep\AI\testERP4\dt\Zakupki_2.dt`.

### 4. Путь к лог-файлу restore
Куда 1С:Предприятие пишет журнал восстановления (через `/out <путь>`).
Рекомендуется хранить рядом с DT-файлом.
Пример: `C:\Commons\rep\AI\testERP4\dt\log.txt`.

### 5. Путь к платформе 1С
Полный путь к `1cv8.exe` (режим DESIGNER).
Пример: `C:\Program Files\1cv8\8.3.27.2224\bin\1cv8.exe`.

### 6. Путь к базе клиента тестирования
Полный путь к каталогу информационной базы (ИБ) клиента тестирования.
**Важно:** путь должен СОВПАДАТЬ с базой, на которую настроен профиль клиента тестирования.
Получить из `manage_test_client_profiles(action="get_list")` → поле «Строка подключения».
Пример: `c:\Bases\Тест_ERP`.

### 7. Имя пользователя 1С
Имя пользователя ИБ с административными правами (для `/RestoreIB`).
Пример: `Администратор`.

### 8. Путь к исходникам конфигурации
Полный путь к корню исходников тестируемой конфигурации (где лежат
каталоги `Documents/`, `Catalogs/`, `CommonModules/` и т.п.).
**Важно:** это ОЧЕНЬ БОЛЬШАЯ директория. Поиск ТОЛЬКО в конкретном
каталоге объекта метаданных с ограничением глубины.
Пример: `G:\rep\erp2\ERP2\src`.

### 9. Имя тестируемой конфигурации
Полное название конфигурации 1С для текстов в feature-файлах и отчётах.
Пример: `1С:ERP Управление предприятием`, `1С:Бухгалтерия`, `1С:ЗУП`.

### Алгоритм чтения для субагента

```
1. Открой файл ПараметрыКонфигурации.MD в корне проекта.
2. Найди нужный параметр в таблице.
3. Используй значение из колонки «Значение».
4. Если значение пустое или содержит `<...>` — сообщи
   Управляющему Агенту: «Не заполнен параметр <имя>».
```
